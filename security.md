# Security Policy…

Care is taken to make sure any software we write does not intentionally contain any vulnerabilities. However, as we all know — in computing, anything and everything can be broken if someone really wants to so if you find any such problems, please could you be as so kind as to report any issues you may come across that *do not* require third-party tools to trigger — via [issues](https://github.com/Mhatxotic/Engine/issues) or contribute fixes via [pull requests](https://github.com/Mhatxotic/Engine/pulls) and we will try our best to fix them.
