# Library files

## Directories required

We have a non-standard layout for library files to help keep all the engine required libraries together for ease of backup.

* Win32 (X86-64) libraries have to end in `64.lib` for the PMU (build) utility to see them.
* Linux (X86-64) libraries have to end in `64.la` for the PMU (build) utility to see them.
* MacOS (Universal X86-64/ARM64) libraries end in `64.ma` for the PMU (build) utility to see them.
